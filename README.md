# Visit the Karoo — visitor-first tourism website

Home leads visitors directly to the trip planner, curated self-drive ideas, a colour-coded map and accommodation.

Main pages: `index.html` (home), `tours.html` (trip planner), `regions.html` (map), `towns.html`, `accommodation.html`, `activities.html`, `events.html`. Additional information: `tourism-network.html` and `about.html` linked from the footer.

The website is a static preview. Tours are suggestions rather than timed/verified routing or pre-booked packages. Google Maps handles directions. Regional boundaries are indicative; confirm roads, times, seasonal conditions, event dates and operator availability.

To publish on Vercel: import this GitHub repository, framework `Other`, root `./`, build command empty, output directory empty. Preview is intentionally `noindex` until data verification and SEO configuration.
